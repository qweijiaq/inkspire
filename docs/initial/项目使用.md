# 项目使用

> 从安装到日常写作，这一篇讲清楚。

## 安装与启动

### 开发模式

```bash
npm install
npm run desktop
```

`desktop` 会同时拉起 Vite 和 Tauri，主窗口启动后自动打开。

只跑浏览器预览：

```bash
npm run dev
```

### 打包安装

```bash
npm run desktop:build
```

产物：

- `src-tauri/target/release/bundle/macos/Inkspire.app`
- `src-tauri/target/release/bundle/dmg/Inkspire_0.1.0_aarch64.dmg`

当前没有开发者签名，Gatekeeper 会拦截；右键「打开」可以绕过。

## 界面

| 区域 | 作用 |
|---|---|
| 左侧栏 | 文件树、搜索、标签、链接、共学 |
| 中间 | 编辑器；打开超过一篇文档时，顶部出现可切换/关闭的文档标签 |
| 右侧 | 大纲与墨墨状态；顶部星标可打开独立的 AI 助手抽屉 |
| 右下角 | 桌宠墨墨；可拖动、点击互动 |

顶部开关：`行内` / `源码`、`专注`、`打字机`、`版本`、`大纲`、`AI`。标签页最多保留最近 8 篇，关闭当前标签会切到相邻文档；关掉最后一篇会回到空书桌。

## 写作

- 输入即保存，停笔 800ms 落盘；保存失败时顶栏会显示「保存失败 · 重试」，点击即可重新落盘
- 列表项末尾按 `Enter` 会自动续写下一个 `-` / `1.` / `- [ ]`；空列表项再按一次退出列表
- 点击任意文字，光标会落在对应字符；标题、列表、代码块和表格之后的段落也保持一致（行级间距用 padding，不破坏 CM6 坐标测量）
- `⌘K` 命令面板：新建、导入、搜索、切换主题、切换源码、AI 动作；输入关键词也会检索正文并跳到命中行
- `⌘⇧D` 打开今天的日记；同一天再次打开会回到同一篇
- 命令面板里还可以从内置模板新建会议纪要、读书笔记、周报、项目计划
- 行首输入 `/` 唤出块命令：标题、列表、任务、引用、表格（也可 `⌘⇧T`）、代码块、数学、Mermaid、分割线，以及让墨墨续写/总结
- `⌘J` 让墨墨在当前光标续写（在编辑器外也生效）
- 切换行内 / 源码不会重建编辑器，撤销历史、滚动位置和光标都会保留
- 选中文字会出现浮动工具条：润色 / 精简 / 翻译 / 解释 / **追问** / **记住**
- 点开图片会进入放大预览，点击遮罩或按 `Esc` 关闭
- `⌘⇧G` 或 AI 菜单里的「生成图解」把当前选区/段落变成流程图或对比图；先预览，点「插入图解」才写入
- 整篇提纲会记住未插入的图；下次打开可继续勾选，或点「重新生成全部」，单节也可「重生成」
- AI 菜单里的「全文润色排版」会通读整篇正文，统一标题层级、段落和列表；结果按 diff 预览，采纳后才替换正文，Front Matter 不动
- AI 菜单里的「生成封面图」会用配置的生图模型生成封面；预览后保存到 `assets/covers/` 并插入 H1 后
- 封面预览下可以写修改要求，点「按这张修改」用参考图继续编辑；目前只支持阿里云百炼，编辑会再消耗 1 张封面额度
- 封面有本机额度：每篇每天最多 3 张，全站每天最多 20 张；生成失败不计数
- 图解预览里可以「导出 PNG」，会生成 2x 图片；桌面版保存到 `~/Downloads/Inkspire`
- 导出 HTML / 打印 PDF / EPUB / DOCX 时，`assets/covers`、本地图片和图解都会自动内联，不依赖相对路径
- `figure` 代码块保存的是图规格 JSON，插入后仍可在源码模式改字、改节点
- 「追问」让墨墨按四层问题引导，不直接给答案；「记住」把选中内容做成复习卡，卡里还可以点「AI 出题」
- 共学页会显示最近阅读位置（读到哪一节/哪一行）、本周报告和遗忘预警，也可以点「考考我」做 3 题小测
- 设置 → 墨墨的记忆：添加/删除长期偏好；同页可以选择墨墨语气：温柔 / 好奇 / 严谨 / 毒舌，只影响表达，不改变事实、本周新增卡片和累计复习次数
- 命令面板里的「文档体检」会列出断链、孤岛、重复标题、空/短文、长期未更新和超大文档，点条目直接跳到对应位置
- 大纲底部点「相关笔记」会按语义推荐 4 篇库内笔记；AI 问答也会先用语义召回，失败自动回退关键词
- AI 菜单或命令面板里的「撤销上次 AI 写入」可回到那次写入前
- 「AI 操作日志」会列出每次 AI 写入，展开可看逐行 diff，也可以回放到某次写入之前；每篇保留最近 20 条
- 设置 → AI 可设「每日字符预算」；超出后文本 AI 入口会被拦下，可「清零今日」或调高上限
- 设置 → AI 的「费用估算」会按内置公开单价统计今日 / 本月 / 累计费用和分模型明细，可清零账本
- 桌面端每 20 秒检查一次 vault；不在编辑时自动合并 iCloud / Git / 其它编辑器的修改，有未保存内容时会延后并提示
- 命令面板的「从磁盘刷新」也可以手动重新扫描 vault
- 左栏「共学」查看连续学习天数、卡片和待复习队列
- 顶部星标打开右侧 AI 助手；点「动作库 · 50」打开 AI 动作库，可按写作/结构/知识/代码/工作筛选；选中动作后会直接生成建议态（命令面板里的 AI 命令同样可用）
- `⌘K` 里输入「知识图谱」可查看双链形成的节点与孤岛，点节点直接打开文档
- `[[双链]]` 可以直接跳转；目标不存在可一键创建
- **表格与 Mermaid 不需要回源码**：阅读模式点卡片打开块编辑器；表格可加行/列、改对齐，图解可实时预览，保存直接回写 Markdown
- `#标签` 会自动收集到左侧「标签」

### AI 设置

1. 打开左下角设置 → AI 接口
2. 选服务商；不想填 Key 可以用「演示模式」
3. 填 Key 后点「刷新模型」拉取模型列表
4. Key 保存在系统钥匙串；设置文件不存明文
5. 打开「隐私模式」后只允许演示模式 / 本地 Ollama / LM Studio；云端服务商会被拦下并提示切换

如果启动时没有弹钥匙串授权，是正常的：只有真正调用 AI 时才会读取。

## 导入与导出

- 拖入 `.md` / `.txt` / `.html` / `.docx` / `.pdf` / `.epub`，也可以拖入 `.zip` 压缩包或直接选择整个文件夹批量导入
- 同一批导入的文档如果互相用 `[标题](文件.md)` 链接，会尽量自动改成 `[[双链]]`；Notion 导出的 UUID 文件名也会按批次映射
- 导入前显示章节预览与质量报告，可逐章勾选、合并、拆分；按书拆出的文章会保持原书章节顺序
- 导出支持 Markdown / HTML / EPUB / DOCX / 打印为 PDF；EPUB 和 DOCX 会带上本地图片与图解
- 设置里可导出/恢复 JSON 备份；备份不会包含 API Key
- 桌面端恢复备份会把文档写回当前 vault（覆盖同名文档、移除备份中不存在的旧文档），重启后不会丢；浏览器预览则恢复到 IndexedDB

## 桌宠互动

右键墨墨（或点桌宠窗右上角的心形按钮）：

- 摸摸 / 喂墨滴 / 击掌：提升亲密度、恢复精力
- 专注 15 / 25 / 45 分钟：桌宠显示倒计时，完成会提醒
- 主窗 / 设置 / 隐藏：不用离开桌宠

亲密度、精力、连续陪伴天数和专注记录存在本机。墨墨会随打字、停笔、保存、AI 思考和报错切换表情。

## 文件夹与保存位置

- 文件树支持多级文件夹；文件夹行悬停会出现「新建文档」「新建子文件夹」「重命名文件夹」三个图标按钮
- 重命名文件夹会把目录内所有文档一起移动，双链标题不变
- 文档行悬停可收藏、重命名、移动到其他文件夹、删除；移动只改路径与标题，不改正文
- 根目录工具条的「＋ 文件夹」可以创建顶层文件夹
- 设置 → 数据 → 保存位置：输入绝对路径后点「应用」，应用会重新加载；留空恢复 `~/Documents/Inkspire`
- 切换保存位置不会自动搬移旧目录里的文档

## 数据存在哪

| 平台 | 位置 |
|---|---|
| 桌面文档 | `~/Documents/Inkspire` |
| 桌面设置 | `~/Library/Application Support/com.inkspire.desktop` |
| 保存位置 | 设置 → 数据 → 保存位置，可改到任意目录 |
| 浏览器预览 | IndexedDB |
| 版本快照 | 本机 meta 表，不写进 vault |

换机器时复制 `~/Documents/Inkspire` 即可带走全部正文。三篇初始文档只会在空 vault 中种入一次；删掉后不会在下次启动时自动复活。

## 排障

### 窗口在别的桌面空间

Alma 全屏时，新窗口可能被放到另一个桌面。退出全屏，或点 Dock 里的 Inkspire。

### 启动白屏

先看是否弹出了钥匙串授权框；旧版本会在启动时读 Key，新版本已改成按需读取。若仍白屏，删除 `~/Library/Application Support/com.inkspire.desktop/webview.log` 后重启，并检查 Vite 端口 5173 是否被占用。

### 关窗时最后一段没保存

桌面端关闭窗口会先尝试落盘最后一段输入再退出；浏览器标签页隐藏时也会立即保存一次。如果进程被强制结束，仍可能丢失最后 800ms 内的输入。

### 保存一直显示「保存中」

确认当前文档没有被外部程序占用；保存状态按文档记录。失败时顶栏会变成「保存失败 · 重试」，点击重试；若仍失败，检查磁盘权限或保存位置是否可写。

## 文档同步规则

任何修复或功能提交前，必须同步这三篇初始文档，并运行：

```bash
npm run docs:check
npm run typecheck
```

`docs:check` 会检查三篇文档是否存在、章节是否齐全、Markdown 示例是否覆盖当前支持的语法；构建前会自动执行。
