# 项目介绍

> Inkspire 是一个本地优先的 Markdown 知识工作台：文档是磁盘上的纯 `.md`，编辑器是所见即所得，墨墨是住在旁边的角色，而不是贴纸。

## 为谁做

- 长期写笔记、但不想被云平台锁死的人
- 需要把 PDF / EPUB / DOCX 里的内容整理进自己知识库的人
- 希望 AI 参与写作、但坚持「采纳才写入」的人
- 喜欢有角色陪伴、但不想被装饰干扰阅读的人

## 四根支柱

### 1. 本地优先

桌面版把每篇笔记写成 `~/Documents/Inkspire` 下的纯 Markdown；浏览器预览使用 IndexedDB，但随时可以导出 JSON 备份。删除应用不会带走你的文字。

### 2. 写得快

- CodeMirror 6 虚拟滚动，8000 行文档输入 P95 约 1ms
- 行内渲染与源码模式一键切换，切换时不丢撤销历史与滚动位置
- 多文档标签页，最多同时保留 8 篇
- 800ms 防抖自动保存、40 个版本快照与回滚

### 3. AI 是建议，不是代笔

- 13 家服务商预设，兼容 OpenAI 协议与 Anthropic Messages
- 续写、润色、精简、总结、翻译、生成小标题
- 写作 / 结构 / 知识 / 代码 / 工作五组，共 50 个可执行动作；命令面板、动作库与 ⌘J 共用同一条执行链路
- 结果先进入建议态，采纳才落笔
- 问答会跨库检索相关笔记，并给出可跳转的来源

### 4. 墨墨是共学伙伴，不是配饰

- 六态表情：待机、专注、思考、开心、惊讶、困倦（`idle / writing / thinking / happy / surprised / sleepy`）
- H1 章节开场、引用首行、提示卡、代码语言栏才出现
- 全部占位排版，不覆盖正文；不同提示类型用不同表情表达语义
- 独立桌宠窗口会跟随打字、停笔、保存、AI 思考与报错
- 共学：选中文字「追问」走四层苏格拉底提问；「记住」生成复习卡，共学页按 1/3/7/14 天复习；最近阅读位置、本周新增卡片与复习次数可见；共学页可小测、看本周报告和遗忘预警；设置里可管理墨墨的长期记忆与语气（温柔/好奇/严谨/毒舌）

## 技术架构

| 层 | 选择 |
|---|---|
| 桌面壳 | Tauri 2 + Rust |
| 前端 | React 18 + TypeScript + Vite |
| 编辑器 | CodeMirror 6 + 自研行内渲染 |
| 文本内核 | Rust ropey 镜像 + UTF-16 changeset + pulldown-cmark 块索引 |
| 存储 | 纯 `.md` 文件；SQLite/FTS5 索引；本机设置 |
| 导入 | PDF / EPUB / DOCX / HTML / Markdown，六维质量评分 |
| AI | Rust SSE 代理 + 前端建议态；Key 存系统钥匙串 |

## 当前状态

已经跑通：桌面双窗口、磁盘 vault、行内 Markdown、表格与 Mermaid 的阅读模式块编辑、代码高亮、导入、双链/标签/大纲、多文档标签页、AI 建议态与跨库问答（含真正的 50 个动作执行链路）、JSON 备份双向恢复（桌面端写回磁盘）、桌宠养成/专注计时、DMG 打包；排版层修复了块级组件导致的鼠标/光标坐标偏移。

界面层按《UI 交互与审美规范》完成了一轮对齐：六态命名统一为 `writing`（不再使用旧名 `typing` / `saved`）、全站线性图标替代 emoji 功能图标、原生 `title` 改为自定义提示气泡、深浅色对比度与焦点环校正、1120 / 760 两档断点、保存失败可重试、图片点击放大、代码高亮跟随主题。

功能层补了一轮文档缺口：行首 `/` 块命令、今日笔记与内置模板、文档移动、`.zip` / 整文件夹导入、括号自动配对、命令面板正文检索、AI 改写逐词 diff 与行内幽灵文本、AI 对话本机留存、宠物空闲 5 分钟入睡。

C14 智能配图 POC：六种 AI 图解 + 整篇 H2 提纲（单节重生成、未插入提纲可恢复）+ 结构/DOM 文字溢出检查 + 2x PNG 导出；封面用 qwen-image 生成、支持参考图继续修改并保存到 `assets/covers/`，设每篇每日额度；HTML/EPUB/DOCX/打印 PDF 会自动内联本地图片和图解。视频和图生视频仍未做。搜索面板的“语义”模式已接真实 embedding（阿里云 `text-embedding-v3`，本地缓存向量）。

AI 层新增「全文润色排版」：整篇正文统一标题层级、段落和列表，结果按 diff 预览，采纳后才替换正文；图片与说明文字在编辑器和 HTML / EPUB 导出里居中。

AI 层新增语义问答：搜索面板、问答召回和大纲「相关笔记」共用同一份 embedding 缓存，服务商不支持时自动回退关键词；AI 写入有逐行 diff 日志并可回放到任意一条之前；设置里可设每日字符预算，并按内置单价查看今日 / 本月费用。桌面端每 20 秒监听 vault，不在编辑时自动合并 iCloud / Git 的外部修改。

维护层新增「文档体检」：命令面板可扫描断链、孤岛、重复标题、空 / 短文、长期未更新和超大文档，点击直接跳到文档位置；只读扫描，不自动改文件。

界面细节也做了一轮第一视角修整：列表回车继续列表，不再把上一项误判成 setext 标题；`_` / `__` / `***` 等常见 Markdown 写法可直接渲染；表格阅读模式补齐表头，编辑改为“工具栏管当前列 + 行号 + 常显删除”，表头吸顶；`/` 菜单会在视口内展开、默认选中第一项，`⌘⇧T` 可直接插入表格；AI 动作库按钮改为自动换行、按钮加高；所有确认、模板、记忆卡、小测、周报弹窗统一了标题、留白与关闭按钮。AI 助手从窄侧栏移到右侧独立抽屉，顶部星标开关；命令面板可打开知识图谱。

仍在路上：签名公证、保存路径完全切到 Rust changeset、移动端真机与同步。
